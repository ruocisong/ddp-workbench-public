# Current Public Repository Status

**Updated:** 23 August 2026

This repository is the public, citable project entrance for **Antica Fiamma (AF)**. It is intentionally not a mirror of the private production and research repository used to build and operate the live environment at [anticafiamma.it](https://anticafiamma.it).

## What This Repository Represents

The public repository is maintained to make AF's scholarly architecture, project-owned software, rights posture, source provenance, citation information, public interface shell, selected method-facing utilities, and rights-safe structural samples inspectable without exposing private research work or redistributing source material beyond its confirmed permissions.

It should therefore be read as a curated public research artifact, not as a dump of the project's internal development history.

## Public And Private Boundaries

The private production repository contains active development, release coordination, internal research material, source-sensitive inputs, generated runtime assets, review traces, and operational state that do not belong in a public repository.

The public repository may receive selected updates from that private workspace when they are:

- project-owned and appropriate for public release;
- useful for understanding the scholarly interface or method;
- compatible with the project's source and rights boundaries; and
- free of private correspondence, credentials, source-sensitive corpora, internal review material, or publication drafts.

The two repositories are **not expected to have identical file trees, Git history, or commit sequences**. Public omission does not by itself imply that a feature is absent from the live AF environment.

## Source Accountability

AF distinguishes among:

1. Dante's text and cited source editions;
2. commentary material sourced through the Dartmouth Dante Project (DDP);
3. project-authored software and documentation;
4. project-derived scholarly structures such as navigable loci, authority links, comparison views, and other inspectable reading aids; and
5. experimental or internal research material that is not part of the public scholarly object.

The public repository is designed to make these layers legible without collapsing their different rights or evidentiary statuses.

Those licences do **not** automatically apply to DDP-derived commentary, third-party texts, images, editions, databases, or other source material. AF holds written authorisation for the current academic, non-profit website use of DDP-derived material; that permission is not represented as a general corpus-redistribution licence.

See [LICENSES.md](../../LICENSES.md) and [rights-and-permissions.md](rights-and-permissions.md) for the detailed boundary.

## Relationship To Version 1.0.0

The Zenodo deposit for version 1.0.0 remains the fixed archival snapshot published on 22 July 2026. This GitHub repository is a living public repository and may continue to receive documentation, software, and public-interface updates after that release.

A later GitHub commit therefore does not silently revise the archived 1.0.0 object. When a new citable release is prepared, it should receive its own release record and provenance statement.

## Current Principle

AF's public repository should expose enough to understand, inspect, cite, and responsibly reuse the project while exposing no more private or source-sensitive material than the public scholarly object requires.
